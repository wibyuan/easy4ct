## 3. 各块详案

### 块 4：res-07c-D-可约与收缩判据

**动机**：res-07b 定理（lifts 一致）给出"外部染色 ⟹ 一致集"；现在反向利用：如果最小反例 T 含标准构型 K，外部 H 的三染色抬升集 C₁ 是一致集且 C₁⊆C′（C′ = C*−C 的最大一致子集）；若 C′=∅ 即矛盾（D-可约）。但对 633 构型中其余者，C′ 非空——RSST 的办法是"收缩"：把 K 内部选定的 1-4 条边 X 收缩后得到更小图，最小反例保证其可 4-染色，再通过"模 X 三染色"反推 T 可染色。为何不直接用收缩操作？主论文 L108 明言：收缩带来记号困难（收缩后同一条边是否仍是原来那条边？），于是把"收缩后的染色"转述为"模 X 三染色"（不改变图）。为何要求稀疏：L548-550 说非稀疏收缩能做的稀疏收缩也能做，是免费简化。

**定义**：
- 定义（稀疏集）（转述 L110）：$X\subseteq E(G)$，每个有限区域至多接一条 X 边、无限区域不接 X 边。
- 定义（模 X 三染色）（转述 L112-116）：$\kappa:E(G)-X\to\{-1,0,1\}$；区域三边皆不在 X 则三色互异；恰 g∈X 则其余两边同色（=收缩 X 后的三染色）。
- 定义（D-可约）（转述 L204）：自由补全 S 与环 R 上，C*−C 的最大一致子集 C′=∅。
- 定义（contract）（转述 L208，术语候选见 §4）：$X\subseteq E(S)-E(R)$ 非空、稀疏于 S、且 C′ 中无边染色是 S 的模 X 三染色在 R 上的限制。

**定理**：
- 定理（最大一致子集存在）：空集一致 + 一致集之并一致 ⟹ 任一染色集有唯一最大一致子集（L190）。须先于 D-可约定义（良定义性）。
- 定理（模 X 三染色存在）=(2.5)（转述 L122-136）：T 最小反例、X 稀疏非空、无圈 C 使 |E(C)−X|=1 ⟹ T 有模 X 三染色。证明全程转述：收缩得 S（衔接 res-06 收缩保持平面性）→ 更小 → 最小反例给 4-染色 → 异或规则导出 κ（衔接 res-05 Tait 转化与 res-07b 的 $\{-1,0,1\}$ 命名）。条件"无圈 C 使 |E(C)−X|=1"的动机要讲：等价于收缩后无环。
- 定理（(3.2) 计算机验证）（转述 L222 + 本文作者复跑佐证）：633 构型中 X=∅ 者 D-可约；否则 1≤|X|≤4 且 X 是 contract。加粗边约定以"清单见下一节"指代（衔接块 6）。

**衔接**：C′ 的直觉（外部染色中与内部最兼容的部分；C′=∅ ⟹ 外部与内部完全矛盾）在动机段展开（DEVLOG 块 4 既定）。

### 块 5：res-07d-从自由补全回到 T

**动机**：K 出现在 T 中时，自由补全 S 未必是 T 的子图（L226 明言）——S 只是理想化环境。桥有三步：投影 φ 把 S 的顶点/边/区域映进 T（(3.3)，folklore，RSST 省略证明，**须自证**——本项目最大自证工作项之一）；(3.4) 保证 φ 在环上的限制恰是 res-07b 已定义的"缠绕"（因此定理（lifts 一致）可直接用于 T 的外部）；短圈引理 (3.5) 与 triad (3.6) 保证 (2.5) 的应用条件"无圈 C 使 |E(C)−φ(X)|=1"成立（内部 6 连通 ⟹ 无短圈）。最后 (3.7) 拼装全部构件。

**定义**：
- 定义（投影）（转述 L228-234，术语候选见 §4）：φ: V(S)∪E(S)∪F(S) → V(T)∪E(T)∪F(T)，保关联；单射性只对无限区域相邻者放宽。
- 定义（对应投影）（L238 命名）。
- 定义（triad）（转述 L242-248，术语候选见 §4）：|X|=4 时 v∈V(G(K))，至少 3 个邻接 v 的顶点与 X 中边相接，且 γ_K(v)=5 时 X 不完全面向 v（"面向"需定义：e 面向 v ⟺ e 与 v 共面且 e 不接 v，L242 逐字）。
- 定义（短圈）（可选引入，与 res-06 内部 6 连通定义衔接）：长度≤5、两侧都有顶点（5 圈要求两侧各≥2）的分离圈。

**定理**：

### 块 8：res-07g-三染色的枚举与一致集的迭代

**动机**：环尺寸 14 时 3^14≈478 万染色、约 148 万平衡有符号匹配、约 2000 万染色-匹配对（Gonthier §5.2），手算不可能。理论保证已有（(3.1) 定理（lifts 一致）+ 空集/并封闭），机器只需做"迭代删除"：从全集出发，反复删去不满足闭包条件的染色与匹配，直到不动点（1401.6481 §3 的 M_i/C_i 双序列）；不动点定理（C_i=C_{i+1} ⟹ C′=C_i）保证正确性。枚举三染色本身用位运算（值域 {1,2,4} 而非 {1,2,3}——"加倍"操作 = 颜色递增循环，8 为溢出标记），配合 strip 的边编号（每边尽量多共面后继边，使禁忌集 F_j 预计算）。
